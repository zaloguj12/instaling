=== INSTALING BOT - PROJECT LOG ===
Last updated: full hint context sent to API, first word extracted from result

--- WHAT THIS PROJECT DOES ---
A Python bot for the Polish school vocab site instaling.pl.
It reads a designated area of the screen using OCR, translates the
detected Polish word/hints to Spanish using the MyMemory free API,
and pastes the first word of the result into a focused textbox with Ctrl+V.

words.json is used as a cache only - it is never manually edited.
Translations are fetched from the API and stored automatically.

--- FILES ---
main.py          - The main bot script
words.json       - Translation cache (auto-managed, do not edit manually)
requirements.txt - Python dependencies
progress.txt     - This file

--- HOW IT WORKS ---
1. Script loads words.json cache
2. User presses ENTER to set the top-left corner of the screen region
3. User presses ENTER again to set the bottom-right corner
4. Script loops, waiting for ENTER each round
5. Screenshots the region, runs OCR to extract text
6. Validates the raw OCR output
7. Checks words.json cache using the full raw hint string as key:
   - CACHE HIT  -> uses cached translation immediately
   - CACHE MISS -> normalizes hints, sends full context to MyMemory API,
                   extracts first word from result, saves to cache
8. Waits 2 seconds, then pastes the first Spanish word with Ctrl+V
9. ESC exits the loop

--- WHY SEND FULL HINT STRING ---
Instaling shows multiple hints separated by semicolons, e.g.:
  "w; w srodku; wewnatrz; za"
Sending only "w" to the API gives wrong results ("h") because
single letters are ambiguous without context.
Sending the full string "w, w srodku, wewnatrz, za" lets the API
correctly identify the meaning as "en" (in/inside).
The cache key is the full raw hint string so the same combination
is never re-requested.

--- OCR VALIDATION ---
The raw OCR output is validated before translation:
- Empty or whitespace-only output           -> skip
- Output containing digits                  -> skip
- Less than 50% alphabetic characters       -> skip (OCR garbage)
- First hint is an Instaling UI string      -> skip

IGNORED UI STRINGS:
  synonim, synonym, przyklad, przyklady,
  definicja, definition, tlumaczenie, przetlumacz

--- HOW PASTING WORKS ---
The first word of the translation is copied to clipboard with pyperclip,
then pasted into the focused textbox with Ctrl+V via pyautogui.
Works for all characters including accented Spanish ones.
Instaling does not detect paste vs typing so this works fine.

--- TRANSLATION API ---
Service: MyMemory (https://api.mymemory.translated.net)
Free, no API key required.
5000 words/day free limit - more than enough for Instaling sessions.
Cached words are never re-requested.

--- DEPENDENCIES ---
- pytesseract    (OCR engine Python wrapper)
- Pillow         (screenshot / image handling)
- pyautogui      (keyboard automation / hotkeys)
- keyboard       (keypress detection)
- pyperclip      (clipboard access for paste)
- requests       (HTTP calls to MyMemory API)
- Tesseract-OCR  (installed at C:\Users\patri\AppData\Local\Programs\Tesseract-OCR)

--- SETUP STEPS ---
1. Install Python packages:
   pip install -r requirements.txt

2. Tesseract is already installed at:
   C:\Users\patri\AppData\Local\Programs\Tesseract-OCR\tesseract.exe
   Path is hardcoded in main.py. Update if reinstalled elsewhere.

3. Run the bot:
   python main.py

--- KNOWN LIMITATIONS ---
- OCR may still misread words if the region includes extra UI elements.
  Keep the region tight around just the word text.
- MyMemory free tier allows 5000 words/day. Resets daily.
  Cached words are never re-requested so this limit is rarely hit.
- Do not overwrite the clipboard in the 2 second window before paste.
